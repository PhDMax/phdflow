## Session summary — v0.25.1 (July 2026)

### Released
PhDFlow v0.25.1 — Stats Assistant overhaul + favorites deduplication.

### Changes this session

#### Fixed: Favorites deduplication
Tools starred to the ⭐ Favorites section now appear **only** there and not
again in their original sidebar section (Workspace/Tools/Feeds). Fixed by
building a `favSet` in `renderSidebar()` before the section loop and
filtering with `sectionIds.has(id) && !favSet.has(id)`.

#### Added: Stats Assistant (replaces R Assistant)
The "R Assistant" was fully reworked into a three-tab Stats Assistant:

1. **💬 Chat tab** — Dr. Stats, a chat-based consulting statistician powered
   by Odysseus. Maintains `_statsChatHistory` client-side and passes the full
   history + a ~40-line system prompt on every call. Partial DOM updates
   preserve the textarea while waiting for an AI response.

2. **📊 Test Selector tab** — the original guided decision-tree wizard,
   unchanged except for the new language toggle.

3. **⚡ Power tab** — G*Power-style power calculator implemented in vanilla JS
   (no external libraries). Supports independent t-test, one-sample/paired
   t-test, one-way ANOVA, correlation, chi-squared, and multiple regression.
   Solves for N, power, or effect size. Statistical math: regularized
   incomplete beta (Lentz continued fraction), non-central chi-squared
   (Poisson mixture series), exact t-quantiles (bisection).

#### Added: Multi-language code output
Code snippets in the Test Selector tab are now available in **R** (original),
**Python** (scipy / pingouin / statsmodels / sklearn), and **SPSS** syntax.
New `PYTHON_RESULTS` and `SPSS_RESULTS` objects cover all 20 test types.
A language toggle (R | Python | SPSS) sits above the code panel.

Wiki updated: `Utilities.md` (Stats Assistant section rewritten), `Home.md`
(Utilities row description updated).

## Session summary — v0.25.0 (June 2026)

### Released
PhDFlow v0.25.0 — personalization features.

### Changes this session

#### Added: six personalization features
1. **Interface Density** — Settings → Personalize → Interface Density lets
   users pick Compact, Comfortable (default), or Spacious layout. Sets
   `document.documentElement.dataset.density`, used by CSS to adjust
   spacing/padding throughout the app.
2. **Custom Accent Colour** — alongside the six built-in themes, a new
   "Custom" swatch opens a colour picker. `_genPalette(hex)` derives a full
   Tailwind-style shade scale from any chosen colour and injects it via a
   `<style id="ph-accent-style">` block, overriding `.bg-indigo-*`,
   `.text-indigo-*`, `.border-indigo-*`, `.nav-btn.active`,
   `.accent-indigo-600`, and `#dash-fab-btn` with `!important`.
3. **Per-Project Icons** — the project create/edit modal now has an emoji
   icon picker (`pmSetIcon`); the chosen icon is saved on the project and
   shown on project cards and the project detail header.
4. **Favorites Quick-Access Bar** — in the sidebar tool picker (opened from
   Settings), each tool card has a ☆ star (`_toggleFavoriteStar`) that pins
   it to a new "⭐ Favorites" section at the top of the sidebar
   (`state.favoriteTools`).
5. **Research Area field presets** — Settings → Personalize → Research Area
   lets users pick their field (Lab Sciences, Humanities, Social Sciences,
   CS & Engineering, Other) and click "Apply suggested setup"
   (`_doApplyFieldPreset`) to configure sidebar tools, dashboard widgets,
   unit-converter category, and tool packs in one step (`_FIELD_PRESETS`).
   Fully reversible via the standard undo toast.
6. **Specialty Tool Packs / Lab Tools** — Settings → Personalize → Specialty
   Tool Packs gates optional tool sets behind `state.enabledPacks`
   (`_PACK_TOOLS`/`_TOOL_PACKS`/`_availableTools()`). The first pack, "Lab
   Tools" (new `src/views/lab_tools.js`), adds a sidebar view with three
   wet-lab calculators: Dilution (C₁V₁=C₂V₂), Molar Mass (formula parser
   with parentheses/brackets and hydrate notation, elements H–U), and
   Solution Prep (mass needed for a target molarity/volume).

All six features were verified end-to-end via Playwright in both light and
dark themes (31 screenshots), including numeric checks of the lab
calculators (e.g. CuSO4·5H2O = 249.677 g/mol). No console/page errors in
real usage paths.

Wiki updated: `Settings-and-Vault.md` (Personalize section), `Projects.md`
(icon field), `Home.md` (new Lab Tools row), and new page `Lab-Tools.md`.

### Standard release process (six steps + verification)
1. `node scripts/release.mjs [patch|minor|major]`
2. Update wiki pages for any new/changed views
3. `node scripts/wiki-push.mjs`
4. Update this file (`CLAUDE.md.txt`) with a session summary, then
   `node scripts/push.mjs`
5. Verify `CLAUDE.md.txt` and any changed wiki pages match what's live on
   GitHub (`curl raw.githubusercontent.com/...` + diff — `gh` CLI is not
   available in this environment)
6. Check the GitHub release page (via the API, using the token from `.env`)
   for correct title, changelog, and all 8 assets
