## Session summary — v0.24.0 (June 2026)

### Released
PhDFlow v0.24.0 — PDF Tools expansion + OCR.

### New features this session

#### PDF reader fix
pdf.js's fetch-based stream always returns status 0 for `file://` URLs, which
pdf.js treats as a fatal error even though the file loads fine. Now reads the
PDF as bytes via IPC and passes it to `getDocument({ data })` instead. Also
added polyfills (main thread + pdf.js worker) for `Uint8Array.toHex/toBase64`,
`Map.getOrInsertComputed`, `Math.sumPrecise`, and switched the text layer to
the new `TextLayer` class — needed for bundled pdf.js 6.x on current
Electron/Chromium.

#### PDF Tools — 6 new operations
- **Page Manager** — drag-and-drop visual page reorder, rotate, delete
  (`src/views/pdf-page-manager.js`)
- **Watermark** — text or image overlay, configurable opacity/rotation/position
- **Metadata** — view and edit title/author/subject/keywords etc.
- **Insert Blank Pages** — at any position, any standard page size
- **Crop** — set margins via numeric inputs
- **PDF ⇄ Images** — export pages to PNG/JPEG, or build a PDF from images

#### OCR — make scanned PDFs searchable
Adds an invisible, selectable text layer over scanned pages without changing
how they look (English only for now, fully offline). The renderer pre-renders
each page to PNG via pdf.js; the main process runs Tesseract.js and overlays
recognized words with `pdf-lib` (`drawText(..., { opacity: 0 })`), sized to
match the original word's width for natural text selection. Trained data is
bundled as a gzipped ~1.9MB file at `resources/tessdata/eng.traineddata.gz`.
electron-builder excludes the unused tesseract.js browser bundles and
SIMD/LSTM wasm variants (~37MB) to keep the installer size down.
