## Session summary — v0.23.3 (June 2026)

### Released
PhDFlow v0.23.3 — all 6 artifacts uploaded.

### Bug fixes this session

#### grants.js — broken function name (crash)
`_buildGrantKeywords` called at 3 sites but function is named `_buildApiKeywords`. Was a ReferenceError that crashed the entire Grant Search tab. Fixed with replace_all.

#### grants.js — unsafe JSON.stringify in onclick
`trackLiveGrant(${JSON.stringify(g).replace(...)})` embedded full grant object JSON in an HTML attribute — fragile with special characters. Fixed by adding `_liveGrantCache` map; onclick now passes just `g.id`.

#### renderer.js — sidebar drag-and-drop order not saved
`renderSidebar` iterated `ALL_TOOLS` (fixed order) and only checked membership in `enabled`, ignoring its order. Fixed by iterating `enabled` first and looking up each tool in `ALL_TOOLS`.

#### renderer.js — sidebar splice off-by-one
After removing the dragged item with `splice(from, 1)`, the target index wasn't adjusted. When dragging downward (from < to), item landed one position too far. Fixed: `splice(from < to ? to - 1 : to, 0, _sbDragId)`.

#### dashboard.js — widget splice off-by-one (same column)
Same issue as sidebar: same-column downward drags placed widget one position too far. Fixed: `if (srcCol === destCol && fromIdx < toIdx) toIdx--`.

#### renderer.js / dashboard.js — rearrange mode
Drag-and-drop now gated behind an explicit "⠿ Rearrange" toggle on both sidebar and dashboard. Items are not draggable by default.
