## Session summary — v0.23.0 (June 2026)

### Released
PhDFlow v0.23.0 — all 6 artifacts uploaded (Setup.exe, Portable.exe, latest.yml, Source.zip, Source.tar.gz, README.md).

### What was built

#### Release automation scripts
- `scripts/push.mjs` — auto-commits all changes with a generated conventional commit message, then pushes
- `scripts/release.mjs` — bumps version, regenerates README from live nav config, builds, creates source archives, pushes, creates GitHub release, uploads 6 artifacts
- `scripts/wiki-push.mjs` — commits + pushes wiki with token auth

When user says "push" → `node scripts/push.mjs`
When user says "release" → `node scripts/release.mjs [minor|patch|major]`, update wiki pages, `node scripts/wiki-push.mjs`

#### Paper Library — PDF features
Three new capabilities in the paper detail modal:
- **📎 Attach local PDF** — file picker, links PDF to paper entry (no copy made)
- **🔍 Find open-access PDF** — queries Unpaywall by DOI, downloads and attaches silently; shows inline status
- **✕ Detach** — removes the PDF link from the paper
- **📖 Read & Annotate** already existed but was only reachable for papers imported as PDFs; now accessible for any paper once a PDF is attached
