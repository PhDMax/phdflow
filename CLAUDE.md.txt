## Session summary — v0.23.2 (June 2026)

### Released
PhDFlow v0.23.2 — all 6 artifacts uploaded.

### What was built this session

#### Sidebar drag-and-drop fix
Root cause: `renderSidebar` iterated `ALL_TOOLS` (fixed order) and only checked if each tool was *in* `enabled`, ignoring the custom order in `state.sidebarTools`. Fixed by iterating `enabled` first and looking up each tool's metadata from `ALL_TOOLS`.

#### Rearrange mode (sidebar + dashboard)
Drag-and-drop is now behind an explicit toggle:
- **Sidebar**: **⠿ Rearrange** button at the bottom activates drag mode (grab cursor, ⠿ handle on items). **✓ Done rearranging** exits it. Clicking nav items is disabled during rearrange mode.
- **Dashboard**: **⠿ Rearrange widgets** link below the header activates mode (dashed indigo outline + grab handles on widgets). **✓ Done** exits it.

#### Calendar — 6 new event types (v0.23.1)
Added: Supervision, Workshop, Defense/Viva, Travel, Social, Holiday/Leave — bringing total from 10 to 16 types. All rendering code derives from `_calTypeConf()` so the new types work everywhere automatically.

#### openPhDFlowFolder defensive fix (v0.23.1)
Added try/catch and proper `await` to `openPhDFlowFolder` in renderer.js. Previously an unhandled rejection could cause unexpected behaviour; errors now surface as a toast.

#### Paper Library — PDF features (v0.23.0)
- **📎 Attach local PDF** — file picker, links PDF to any paper entry
- **🔍 Find open-access PDF** — queries Unpaywall by DOI, downloads and attaches silently
- **✕ Detach** — removes the PDF link from a paper
