# PhDFlow — User Guide

**PhDFlow** is a free, offline-first desktop productivity app built for PhD students and researchers. Everything runs on your machine — no cloud account required.

---

## Tools

| Tool | What it does |
|------|-------------|
| [Dashboard](dashboard.md) | At-a-glance overview of your research life |
| [Projects](projects.md) | Track research projects, milestones, and progress |
| [Paper Library](library.md) | Manage your reading list and PDFs |
| [Grant Writing](grants.md) | Track grants, deadlines, and budgets |
| [Literature Feed](news.md) | Follow RSS feeds and arXiv topics |
| [Notes](notes.md) | Quick markdown notes with tag organization |
| [Whiteboard](whiteboard.md) | Freehand drawing and idea sketching |
| [Utilities](utilities.md) | PDF tools, unit converter, and more |
| [Discover](discover.md) | Search researchers and papers by topic |
| [Contacts](contacts.md) | Academic contact book |
| [Calendar](calendar.md) | Conference deadlines, meetings, and events |
| [To-Do List](todos.md) | Focused task management |
| [Settings & Vault](settings.md) | App preferences, security vault, personalization |

---

## Getting Started

1. **[Download the latest release](https://github.com/PhDMax/phdflow/releases/latest)**
2. Run the installer — no setup wizard required
3. (Optional) Set a login password in **Settings → App Lock**
4. Start with the **Dashboard** for a quick orientation
