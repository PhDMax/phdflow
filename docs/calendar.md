# Calendar

Track conferences, submission deadlines, meetings, and personal milestones — with optional sync from external calendars.

## Getting started

1. Click **Calendar** in the left sidebar
2. The current month is shown by default
3. Click **+ New Event** to add your first entry

## Adding an event

1. Click **+ New Event** or click directly on a date in the calendar
2. Fill in:
   - **Title** — what the event is
   - **Date** — start date (and end date for multi-day events)
   - **Time** — optional
   - **Type** — Conference / Deadline / Meeting / Personal / Other
   - **Notes** — location, link, agenda
3. Click **Save**

## Event types and colours

| Type | Colour | Use for |
|------|--------|---------|
| Conference | Blue | Events you're attending or presenting at |
| Deadline | Red | Submission and funding deadlines |
| Meeting | Green | Supervisor meetings, seminars |
| Personal | Purple | Holidays, appointments |
| Other | Grey | Everything else |

## Importing from an ICS file or URL

Sync events from Google Calendar, Outlook, or any calendar service:

1. Go to **Settings → Calendar**
2. Paste an **ICS URL** (most calendar apps provide this under "Share" or "Export")
3. Click **Sync** — events import into the Calendar view

For a one-off import:

1. Export an `.ics` file from your external calendar app
2. In PhDFlow Calendar, click **Import ICS** and select the file

## Navigating

- Use **← →** arrows to move between months
- Click **Today** to jump back to the current date
- Switch between **Month**, **Week**, and **List** views using the view buttons

## Tips

- Add conference paper deadlines as **Deadline** events well in advance (submission date, camera-ready date, registration deadline)
- Upcoming events for the next 7 days appear automatically on the **Dashboard**
- Use the **Notes** field to store paper submission links or meeting agenda points
