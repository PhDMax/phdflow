# Paper Library

Your personal academic reading list — store PDFs, add metadata, and track what you've read.

## Getting started

1. Click **Library** in the left sidebar
2. Click **+ Add Paper** to add your first entry
3. Fill in:
   - **Title** — paper title
   - **Authors** — comma-separated
   - **Year** — publication year
   - **DOI / URL** — optional but useful for later retrieval
   - **Tags** — e.g. `methodology`, `related-work`, `to-read`
   - **Notes** — your own comments or highlights
4. Click **Save**

## Importing a PDF

1. Click **Import PDF** on any paper entry
2. Select a PDF from your computer
3. PhDFlow stores a reference to it — you can open it at any time with one click

## Importing citations

You can bulk-import papers from a `.bib` (BibTeX) file:

1. Click **Import .bib** (top of the Library view)
2. Select your `.bib` file
3. All entries are imported; review and edit as needed

## Searching and filtering

- Use the **search bar** at the top to filter by title, author, or tag
- Click a tag chip to filter to all papers with that tag
- Sort by **date added**, **year**, or **title** using the sort dropdown

## PDF tools

PhDFlow includes built-in PDF utilities (accessible via **Utilities → PDF Tools**):

- Merge multiple PDFs into one
- Split a PDF by page range
- Rotate pages
- Add page numbers
- Remove pages

## Tips

- Add a `to-read` tag to build your reading queue
- The **Notes** field supports plain text — use it for brief summaries or key quotes
- Papers appear on the Dashboard under "Recent Papers"
