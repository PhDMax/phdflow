# Notes

A fast, tag-based markdown notepad for ideas, meeting notes, reading summaries, and everything in between.

## Getting started

1. Click **Notes** in the left sidebar
2. Click **+ New Note**
3. Give it a **title** and start typing in the body
4. Add **tags** (comma-separated) to organize by topic
5. Click **Save** — or just navigate away; notes auto-save

## Markdown support

Notes render basic markdown:

| Syntax | Result |
|--------|--------|
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `# Heading` | Large heading |
| `` `code` `` | `inline code` |
| `- item` | Bullet list |
| `1. item` | Numbered list |
| `> quote` | Block quote |

## Organizing with tags

- Type tags in the **Tags** field, separated by commas (e.g. `meeting, supervisor, Q2`)
- Click a tag in the sidebar or note list to filter to matching notes
- Tags are created on the fly — no need to pre-define them

## Searching

Use the **search bar** at the top to find notes by title, body text, or tag.

## Exporting a note

1. Open the note
2. Click the **export** icon (top-right)
3. Choose **Plain text (.txt)** or **Markdown (.md)**

## Tips

- Start each meeting with a new note; add the `meeting` tag to build a meeting log
- Use a `scratch` tag for quick temporary notes you'll clean up later
- Long notes scroll — there's no length limit
