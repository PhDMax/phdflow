# Projects

Track your research projects from idea to completion — with milestones, status labels, and notes.

## Getting started

1. Click **Projects** in the left sidebar
2. Click **+ New Project** (top-right)
3. Fill in:
   - **Title** — a short name for the project
   - **Description** — what the project is about
   - **Status** — Active / On Hold / Completed
   - **Start date** and **Target end date** (optional)
4. Click **Save**

## Adding milestones

Milestones break a project into trackable chunks:

1. Open a project by clicking its card
2. Click **+ Add Milestone**
3. Give it a name and optional due date
4. Check it off when done — progress updates automatically

## Managing projects

| Action | How |
|--------|-----|
| Edit a project | Click the pencil icon on the project card |
| Change status | Edit the project and pick a new status |
| Delete a project | Click the trash icon (confirmation required) |
| Archive / complete | Set status to **Completed** |

## Tips

- Active projects appear on the Dashboard
- Use the **Description** field to keep a mini research diary for each project
- Milestones with past due dates are highlighted automatically
