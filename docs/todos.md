# To-Do List

A focused task manager for your daily research work — quick to add, easy to prioritize, and linked to your Dashboard.

## Getting started

1. Click **To-Do** in the left sidebar
2. Click **+ New Task** or use the quick-add bar at the top
3. Type a task name and press Enter — it's added immediately

## Adding details to a task

Click any task to expand it and add:

- **Due date** — when it needs to be done
- **Priority** — Low / Medium / High
- **Tags** — e.g. `writing`, `lab`, `admin`
- **Notes** — extra context or sub-steps

## Completing tasks

- Click the **checkbox** to the left of a task to mark it done
- Completed tasks move to the **Done** section at the bottom
- Click **Clear Done** to remove all completed tasks at once

## Organizing tasks

| Feature | How to use |
|---------|-----------|
| Priority | Set High/Medium/Low; tasks sort by priority by default |
| Tags | Filter to one area at a time (e.g. show only `writing` tasks) |
| Due date | Tasks overdue are shown in red; due today in amber |
| Search | Type in the search bar to find any task by keyword |

## Keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| Enter (in quick-add) | Add task |
| Click checkbox | Complete task |
| Delete key (task selected) | Delete task |

## Tips

- Keep the list short: aim for ≤ 10 active tasks at a time — move anything else to a project milestone
- Use **High** priority sparingly so it stays meaningful
- Tasks with due dates appear on the **Dashboard** under "Open To-Dos"
- The floating action button (bottom-right, Dashboard) lets you add a task from anywhere
