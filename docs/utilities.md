# Utilities

A collection of practical tools for everyday research tasks — PDF manipulation, unit conversion, and more.

## PDF Tools

All PDF tools work fully offline.

### Merge PDFs
Combine multiple PDFs into a single file.

1. Click **PDF Tools → Merge**
2. Click **Add Files** and select your PDFs
3. Drag to reorder if needed
4. Click **Merge** and choose a save location

### Split PDF
Extract a page range from a PDF.

1. Click **PDF Tools → Split**
2. Select the source PDF
3. Enter the page range (e.g. `1-5` or `3,7,9`)
4. Click **Split** and save

### Rotate Pages
Fix scanned documents with wrong orientation.

1. Click **PDF Tools → Rotate**
2. Select the PDF and choose rotation (90°, 180°, 270°)
3. Apply to all pages or specific ones

### Remove Pages
Delete unwanted pages from a PDF.

1. Click **PDF Tools → Remove Pages**
2. Specify page numbers to remove (e.g. `2,5,8-10`)
3. Save the result

### Add Page Numbers
Stamp page numbers onto a PDF.

1. Click **PDF Tools → Page Numbers**
2. Choose position (bottom-center, top-right, etc.)
3. Set starting number and font size
4. Click **Apply**

### Export to PDF
Convert any Note or text content to a PDF.

1. Open a Note
2. Click **Export → PDF**

---

## Unit Converter

Quickly convert between common scientific units.

1. Click **Utilities → Unit Converter**
2. Select a category (Length, Mass, Temperature, Pressure, etc.)
3. Type a value in any field — all other units update instantly

---

## Tips

- PDF tools process files locally — nothing is uploaded anywhere
- The output PDF is always a new file; the original is never modified
- Use **Merge** to combine chapters of your thesis before submission
