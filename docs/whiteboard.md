# Whiteboard

A freehand digital canvas for brainstorming, sketching diagrams, and visual thinking.

## Getting started

1. Click **Whiteboard** in the left sidebar
2. The canvas opens blank and ready to draw
3. Select a tool from the toolbar at the top

## Drawing tools

| Tool | Shortcut | Use for |
|------|----------|---------|
| Pen | P | Freehand drawing |
| Line | L | Straight lines |
| Rectangle | R | Boxes and frames |
| Circle | C | Circles and ellipses |
| Text | T | Labels and annotations |
| Eraser | E | Remove strokes |
| Select | S | Move or resize elements |

## Styling

- **Colour picker** — choose stroke or fill colour
- **Stroke width** — thin, medium, thick
- **Opacity** — useful for layering

## Managing your whiteboard

| Action | How |
|--------|-----|
| Clear canvas | Click **Clear** in the toolbar (confirmation required) |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Export as PNG | Click **Export → PNG** |
| Export as SVG | Click **Export → SVG** |

## Tips

- Use the whiteboard for concept maps before writing — outline relationships between ideas visually
- Export to PNG and paste into your thesis document or presentation
- The canvas is infinite — scroll and zoom to use as much space as you need
- Each whiteboard session is auto-saved when you navigate away
